# 示例对话提示词与完整演示

> 以下「完整演示」基于 **2026-10-12** 真实调用官方 `mcd-mcp` 的结果（上海静安寺 · 到店自取）。  
> 价格、库存、券会随时间变化；复现时请以当次 `calculate-price` 为准。  
> **本演示未调用 `create-order`**（止于确认前方案）。

---

## 1. 只要方案（推荐开场）

```text
用 mcd-budget-order：预算 40 元，1 人，到店。
位置：上海 静安寺。先查券再比价，不要下单，只给最省方案。
```

## 2. 确认下单（方案确认后）

```text
取餐方式选店内取餐柜（locker-in），确认下单。
```

## 3. 超预算场景

```text
预算 20 元，2 人，到店，位置：深圳 科技园。
如果做不到预算内，给出最接近方案和差额，不要下单。
```

## 完整演示对话（实录摘要）

### 用户

```text
用 mcd-budget-order：预算 40 元，1 人，到店。
位置：上海 静安寺。先查券再比价，不要下单，只给最省方案。
```

### Agent 执行流水线

1. `now-time-info` → `2026-10-12 20:36`（夜市档）
2. `query-my-coupons` → 券包含「中薯条买一送一」「王牌小食拼」「9.9元中杯冰美式」等
3. `query-nearby-stores`（`searchType=2`, `beType=1`, city=上海, keyword=静安寺）
4. 用户侧默认选最近店：`storeCode=1450002`（**不传 beCode**）
5. `query-store-coupons`（`orderType=1`, `beType=1`, 不传 beCode）
6. `query-meals` 同参
7. 多组 `calculate-price` 比价（单位分→元）

### Agent：选店

附近到店门店（节选）：

| 门店 | storeCode | 距离 | 状态 |
|---|---|---|---|
| 麦当劳上海静安寺餐厅 | 1450002 | 134m | 营业中（已选） |
| 麦当劳上海越洋广场餐厅 | 1450133 | 194m | 营业中 |
| 麦当劳上海南京西路Eco1788餐厅 | 1450224 | 221m | 营业中 |

### Agent：真算价比价（预算 ¥40）

| 候选 | 用券 | 应付 | 预算内 |
|---|---|---|---|
| **大堡口福三件套 ×1** | 无 | **¥22.90** | 是 · **最低** |
| 麦乐鸡经典中套餐 ×1 | 无 | ¥25.00 | 是 |
| 龙焰鸡腿堡三件套 ×1 | 无 | ¥26.90 | 是 |
| 精选超值随心配 + 中薯条买一送一 | 薯条券 | ¥27.40 | 是 |
| 大堡口福三件套 + 冰美式中杯 | 9.9 冰美式券 | ¥32.80 | 是 |

说明：券组合应付仍高于「大堡口福三件套」单方案，故最优为无券套餐。

### Agent：确认前方案

```text
【到店省钱方案】
门店：麦当劳上海静安寺餐厅（1450002）
人数：1｜预算：¥40
菜品：
- 大堡口福三件套 x1
用券：无（比价后该套餐应付更低）
原价：¥22.90｜优惠：¥0.00｜应付：¥22.90
取餐方式候选项：堂食(eat-in)｜外带-店内取餐柜(locker-in)
状态：可下单（低于预算 ¥17.10）

回复「确认下单」并选定取餐方式将创建真实订单并可能产生支付；
回复「取消」或提出修改。本演示不下单。
```
